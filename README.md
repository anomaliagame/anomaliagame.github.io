# ANOMALÍA

Juego de previas para el móvil: retos, caos, votaciones, virus… y misiones secretas.

- El móvil principal lleva las cartas.
- Cada jugador escanea el QR (o abre el enlace) y ve su rol y sus misiones en su propio móvil.
- La sincronización usa un servidor MQTT público (sin cuentas). Si no hay conexión, el juego funciona en un solo móvil.

Archivos: `index.html` (el juego), `mqtt.min.js` (MQTT.js, licencia MIT) y `qrcode.js` (qrcode-generator, licencia MIT).
